# 🤖 TL;DR бот — экономия времени

Telegram-бот, который жмёт длинное в короткое: статьи, посты, голосовые, PDF.

## Что умеет

| Вход | Что делает |
|---|---|
| 📄 Длинный текст/пост/новость | Краткая выжимка прямо в чат |
| 🔗 Ссылка на статью | Скачивает страницу (trafilatura + readability) и пересказывает |
| 🎙 Голосовое / аудиофайл | Расшифровывает Whisper'ом, присылает расшифровку + суть («Это было 3 минуты нытья про работу, суть: бесит начальник») |
| 📑 PDF / DOCX / TXT | Вытаскивает текст и выжимает главное |
| ↪️ Reply на сообщение в группе | Пересказывает то, на что ответили |
| 💬 Пересланное сообщение | Пересказывает пересланное (через `forward_origin` / цитату) |

### Уровни краткости (кнопками или `/level`)
- `1️⃣ Одно предложение` — `/level one`
- `2️⃣ Кратко` — `/level short` (по умолчанию)
- `3️⃣ Подробно` — `/level detail` (структурированный конспект)

Уровень запоминается для каждого чата отдельно (`chat_data`).

## Быстрый старт

```bash
pip install -r requirements.txt
cp .env.example .env   # впиши BOT_TOKEN и OPENAI_API_KEY
export $(grep -v '^#' .env | xargs)
python -m bot.main
```

Docker:

```bash
docker build -t tldr-bot .
docker run --env-file .env tldr-bot
```

## Команды

- `/start`, `/help` — приветствие + кнопки выбора уровня
- `/level one|short|detail` — сменить уровень текстом

## Настройки (env)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` | — | токен от @BotFather (**обязательно**) |
| `OPENAI_API_KEY` | — | ключ LLM-API (**обязательно**) |
| `OPENAI_BASE_URL` | openai.com/v1 | можно указать OpenRouter/локальный шлюз |
| `LLM_MODEL` | `gpt-4o-mini` | модель суммаризации |
| `WHISPER_MODEL` | `whisper-1` | модель распознавания речи |
| `MAX_TEXT_CHARS` | 60000 | сколько текста максимум уходит в LLM |

## Структура

```
bot/
  main.py           # хендлеры Telegram (текст/ссылки/голос/документы)
  summarizer.py     # промпты + запросы к LLM и Whisper
  extract.py        # извлечение текста из PDF/DOCX/TXT
  telegram_utils.py # разбивка длинных ответов, кнопки, загрузка файлов
  config.py         # env-настройки, уровни краткости, лимиты
tests/test_smoke.py # смоук-тест логики без сети
```

## Как это работает

1. Любое входящее сообщение приводится к тексту: ссылка → HTML → читаемый текст; голос → Whisper; документ → pypdf/python-docx.
2. Текст вместе с инструкцией уровня краткости уходит в LLM (OpenAI-совместимый chat completions).
3. Ответ экранируется в безопасный HTML, при длине > 4096 символов режется по абзацам и отправляется частями.
4. Ошибки не падают молча: «Читаю…» превращается в понятное сообщение («сайт закрыт от роботов», «PDF — скан без текста» и т.п.).
